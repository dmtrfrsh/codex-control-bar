# Security

Please do not post credentials, `~/.codex/config.toml`, rollout files, or full
diagnostic snapshots in public issues.

For a security-sensitive report, use a private GitHub Security Advisory after
the repository is published. For ordinary bugs, include the macOS version,
`codex --version`, the Control Bar version, and a redacted reproduction.

The project intentionally does not print or copy MCP credential values. See
[PRIVACY.md](PRIVACY.md) for its local data boundaries.
